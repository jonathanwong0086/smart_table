# 开源多维表格SmartTable v1.6.9 —— 表能分享能转手、公式会自检，一批老坑也填了

***

> **一句话总结**：这版主要干了这几件：📋 **数据表管理**加了所有权转移、表分享，还能手动刷新数据；🧮 **公式字段**更靠谱了——日期/日期时间能自己定显示样式，保存前还会帮你检查公式对不对；🕒 **系统字段**能自己决定显不显示，创建人、更新时间这些想藏就藏；🖼️ **附件预览**能上一张下一张翻着看；另外还修掉了一批烦人的老坑——弹窗被挡、`SECRET_KEY`/`JWT_SECRET_KEY` 缺失导致 Docker 起不来、ARM 跑不起来、Redis 连不上、查找字段在公式里跑不起来、UNIQUE 嵌套数组算错，都收拾了。

## 一、这版最大的变化是啥？

上一版（1.6.8）把公式引擎、成员管理、数据表文件夹这些都铺开了。1.6.9 这版更像在"查漏补缺 + 把常用功能打磨顺"——公式字段以前只能算，现在能管显示、会自检；系统字段以前死板地摆着，现在能配；附件看图、表分享转手，都是大家平时用得上的；再就是把之前部署、弹窗、公式里的一些老坑都填了。

- **数据表管理**：表能转交给别人（所有权转移）、能分享出去，还能手动刷新数据。
- **公式字段**：日期/日期时间能设显示格式了，保存前还会校验公式，写错当场提醒。
- **系统字段**：创建人、创建时间、更新人、更新时间这四个系统字段，现在能配置显不显示了。
- **附件预览**：图片预览支持上一张/下一张，连着看图不用来回点。
- **修掉一批老坑**：弹窗被外层挡住、`SECRET_KEY`/`JWT_SECRET_KEY` 缺失导致 Docker 起不来、ARM 架构跑不起来、Redis 连不上、查找字段在公式里执行不了、UNIQUE 嵌套数组算错，都修了。

下面分开唠。

***

## 二、数据表管理：能转手、能分享、能刷新

这版在数据表本身上加了三个实打实的活儿，都是协作里常碰到的场景。

- **所有权转移**：多维表能"过户"了。以前多维表的归属绑在创建人身上，人走了或者你想交给别人维护，没啥好办法。现在多维表支持所有权转移，把归属转给别的成员就行，交接不抓瞎。
- **数据表分享**：新增表分享功能，想把一张表快速丢给别人协作，分享一下就成，不用搬来搬去导来导去。
- **表格数据刷新**：加了手动刷新数据的按钮和提示。数据被别人改了、或者你刚导入完，点一下就把最新拉下来，不用整个页面重开。

## 三、公式字段：不只是能算，还管显示、会自检

这块是这版的头牌，给所有拿公式算账、做统计的朋友准备的。

### 以前啥情况？

以前公式字段能算，但显示上比较死——日期、日期时间类型没法单独设展示样式，想"只显示年月日"或者"显示到秒"，得靠别的法子绕；而且公式写错了，往往得等保存甚至计算时才发现不对劲，排查起来挺费劲，尤其是长公式，错一个括号找半天。

### 现在咋用？

- **日期/日期时间显示格式**：公式字段现在支持给日期、日期时间类型设显示格式了。比如公式算出的是个日期，你想让它只显示"2026-10-18"还是精确到秒，自己定，展示更舒服。
- **保存前校验**：公式字段在保存前会先校验一遍，写错了（比如引用了不存在的字段、括号没配对）当场就给你红字提示，不用等保存完才发现算不出来。相当于给你配了个"保存前把关的伙计"。

说白了，这版是把公式从"能算"往"算得准、看得顺"又推了一步。平时用公式做台账、做报表的朋友，这版能明显感觉到省心。

***

## 四、系统字段：该露脸的露脸，不该露的藏起来

用得久的朋友都知道，每张表默认都会带创建人、创建时间、更新人、更新时间这四个系统字段。以前它们是"钉死"在那儿的，想藏都藏不掉。

- **四个系统字段可配置显示**：现在能单独开关显不显示了。有些内部表你不想让人看到"谁改的、啥时候改的"，关掉就行；想留痕的（比如审批记录），开着就好。不用再对着一成不变的列发愁，清爽不少。

***

## 五、附件预览：看图能翻页了

把图片当附件传进来，这版看图的体验好了点。

- **上一张/下一张导航**：附件里看图，现在预览能直接上一张、下一张切换。以前一张张点开、关掉、再点下一张，来回折腾；现在在预览里翻就完事，连续看产品图、截图批注顺多了。

## 六、修了哪些 Bug？

这版修掉的老坑不少，挑重点说：

- **弹窗被挡住**：创建和编辑的弹窗加了 `append-to-body`，挂到 body 下，不再被外层容器裁掉或挡住——之前嵌套深的弹窗下半截被"吃掉"、浮层盖不住输入框，现在清爽了。
- **Docker 起不来（密钥缺失）**：修掉了 Docker 默认配置里 `SECRET_KEY`、`JWT_SECRET_KEY` 缺失导致服务起不来的问题，不少朋友卡在这一步，现在顺了。
- **ARM 架构跑不起来**：修了 Docker 镜像在 ARM（树莓派、苹果芯片某些场景、国产 ARM 服务器）上的构建/运行问题，跑 ARM 的朋友能正常用了。
- **老启动脚本还能用**：Dockerfile 加了 `run.py` 兼容转发，旧的启动方式不慌，升级不用改脚本。
- **镜像更干净**：`.dockerignore` 改成 `**/` 前缀，子目录里的 Python 缓存也能正确忽略。
- **Redis 连不上**：修了 Docker 环境下 Redis 连接配置的问题，连不上、连错实例的情况少了。
- **查找字段在公式里跑不起来**：修了查找字段放到公式里没法正常执行的问题——之前在公式里引用查找字段容易"哑火"，现在能正常算了。
- **UNIQUE 嵌套数组**：修了 UNIQUE 函数碰到嵌套数组没展平、导致去重结果不对的问题——用 UNIQUE 做去重的朋友，现在结果准了，不会再悄悄多算或少算。

## 七、升级提醒

几个点留意下：

1. **数据库会自动升级**：这版涉及的迁移走 Alembic 自动迁移，正常启动就行，不用手改表。
2. **Docker/ARM 用户**：之前卡在密钥缺失、ARM 跑不起来的，这版升级后能正常起了；老启动脚本也还能用，放心升。
3. **公式想管显示/怕写错**：升级后去公式字段看看日期格式设置，保存前校验会自动帮你把关。
4. **表要转手/分享**：所有权转移和数据表分享这版都齐了，协作场景直接用起来。
5. **系统字段**：不想暴露谁改的，去字段设置里把显示关掉就行。

## 八、关于 SmartTable

SmartTable 是一个**开源的多维表格系统**，功能上类似飞书多维表格、WPS 多维表格（金山文档多维表格）。

### 核心特性

- **27 种字段类型**：文本、数字、日期、单选、多选、成员、附件、公式、关联、查找、地理位置……基本能想到的字段都有
- **7 种视图**：表格视图、分组视图、看板视图、日历视图、甘特图视图、表单视图、画廊视图
- **主从表 + 树形层级**：记录能挂明细，也能建父子层级
- **70+ 个内置公式函数**：数学（支持运算符）、文本、日期、逻辑、统计、跨表引用
- **完整工作流引擎**：循环、查找记录、发送邮件、记录时间触发器、自定义 Python 脚本
- **插件扩展体系**：前后端都能写插件，附官方示例，想加啥功能自己来
- **实时协作**：多人同时编辑，带单元格锁和冲突检测
- **第三方应用接入**：OAuth2 + 开放 API + 应用审计日志
- **多语言**：界面支持中文 / 英文，自动跟随系统语言
- **多个 Base 模板**：会议管理、学习计划、Bug 追踪、招聘管理、资产管理、OKR
- **仪表盘系统**：KPI 卡片、图表、实时数据展示、分享
- **文档管理**：富文本、Markdown、PDF 导出、版本历史
- **一键启动**：下载 release 包双击即可
- **Docker 一键部署**：内嵌 Redis
- **支持 SQLite 和 PostgreSQL**

### 快速体验

```bash
# 下载 release 包解压后双击 start.bat
# 或 Docker 一键启动
docker run -d -p 80:80 ygbinac/smarttable:latest
```
